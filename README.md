# Before You Paste

Complete static website source, including the latest requested fixes.

## Files
- index.html: page content
- styles.css: responsive design and print styling
- app.js: example tabs, checklist, and practice activity
- favicon.svg: site icon

No build command, dependencies, AI API, account system, or backend is needed.

## Publish using GitHub Pages
1. Create a public repository called before-you-paste. Add a README when creating it so the main branch exists.
2. Extract this ZIP. Upload index.html, styles.css, app.js, and favicon.svg directly into the top level of the repository. Do not upload the ZIP itself or put the files in a nested folder. You can replace the starter README with this one.
3. Commit the uploaded files to main.
4. Open Settings > Pages.
5. Under Build and deployment, select Deploy from a branch.
6. Select main and /(root), then Save.
7. Wait for GitHub to finish deployment. Settings > Pages will show the live site URL.

## Future edits
Update the relevant file in the repository and commit to main. GitHub Pages republishes from the selected branch.

## Local preview
Open index.html in a browser. Clipboard copying may be restricted for local files; it should work on the HTTPS-hosted website.

## Privacy
Checklist choices and practice answers stay in memory and reset on reload. The app contains no analytics, prompt uploads, or feedback form. The hosting provider may process access and security logs.
